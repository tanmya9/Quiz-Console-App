# 🧠 Quiz Console App

A console-based quiz application built in Java using core Object-Oriented Programming concepts.

---

## 📁 Project Structure

```
Quiz-Console-App/
├── Main.java            
├── Question.java        
└── QuestionService.java 
```

---

## 📌 Class Overview

| Class | Responsibility |
|-------|---------------|
| `Question.java` | Blueprint for a quiz question — stores question, options, and answer |
| `QuestionService.java` | Manages questions array, displays quiz, and calculates score |
| `Main.java` | Entry point — creates object and starts the quiz |

---

## 💡 Concepts Used

- Encapsulation — private fields with getters and setters
- Arrays of Objects
- Constructors
- For-each and for loops
- Scanner for user input
